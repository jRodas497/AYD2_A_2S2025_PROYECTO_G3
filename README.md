# SGO-Logic — Proyecto Fase 1 (AYD2)

Documentación de arquitectura para la iniciativa omnicanal de MegaStore, elaborada como Fase 1 del curso Análisis y Diseño de Sistemas 2A (USAC).

> Repositorio: [`AYD2_A_2S2025_PROYECTO_G3`](https://github.com/hricardoavilac/AYD2_A_2S2025_PROYECTO_G3) (Sección A, Grupo 3).

## Empezar aquí
1. Lee `Docs/Analisis/analisis-caso-megastore.md` — resumen del caso, stakeholders, drivers candidatos y riesgos.
2. Lee `CONTRIBUTING.md` — flujo GitFlow del equipo (ramas `master`/`develop`/`feature/*`).
3. Para la defensa: `Docs/Presentacion/slides.html` (diapositivas) y `guion.md` (tiempos y reparto entre integrantes).

## Estructura

| Carpeta | Contenido |
|---|---|
| `Docs/Analisis/` | Análisis del caso (insumo para el DDA) |
| `Docs/DDA/` | Documento de Definición de Arquitectura, por secciones |
| `Docs/ADR/` | Architecture Decision Records (registro vivo) |
| `Docs/Diagramas/` | Vistas arquitectónicas en draw.io — `.drawio` (contexto, componentes, despliegue, bloques) |
| `Docs/Prototipo/` | Flujo principal y mockups no funcionales |
| `Docs/Presentacion/` | Guion de la defensa oral y reportes de avance |
| `Docs/Kanban/` | Especificación del tablero (columnas obligatorias, criterio Backbone-first) |
| `Docs/Enunciado/` | Enunciado oficial del proyecto |
